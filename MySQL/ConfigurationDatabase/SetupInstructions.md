## Part 2 — PHP: Deploy and Configure the API

The two PHP files in `MySQL/ConfigurationDatabase/` must be placed on a web server with PHP and MySQL access. They cannot run from the filesystem — they need a web server.

### 2.1 Check whether Apache and PHP are installed

```bash
apache2 -v
php -v
php -m | grep pdo_mysql
```

If Apache/PHP are not installed:

```bash
sudo apt install apache2 php php-mysql
sudo systemctl start apache2
sudo systemctl enable apache2
```

Verify `pdo_mysql` appears in `php -m`. If it does not:

```bash
sudo apt install php-mysql
sudo systemctl restart apache2
```

---

### 2.2 Choose a deployment location

Two options:

**Option A — Deploy inside the Apache document root** (simplest, suitable for a local lab server):

```bash
sudo mkdir -p /var/www/html/api
sudo cp MySQL/ConfigurationDatabase/API_battery.php     /var/www/html/api/
sudo cp MySQL/ConfigurationDatabase/API_task_config.php /var/www/html/api/
```

The API will be reachable at:
- `http://yourserver/api/API_battery.php?index=16`
- `http://yourserver/api/API_task_config.php?type=parameters&task=Word+Recall&name=RAVLT_Spoken_Immediate`

**Option B — Deploy as a subfolder of the JATOS static files** (only works if Apache serves the NCMBattery assets, not JATOS itself):

```bash
mkdir -p /home/jason/jatos_linux_java/study_assets_root/NCMBattery/api
cp MySQL/ConfigurationDatabase/API_battery.php     /path/to/web_root/NCMBattery/api/
cp MySQL/ConfigurationDatabase/API_task_config.php /path/to/web_root/NCMBattery/api/
```

### 2.6 Update the API URL in WordRecallDatabaseConfig.html

At the top of the configuration block in `html/JATOS/WordRecallDatabaseConfig.html`, find:

```javascript

```

Replace `localhost` with the actual hostname or IP of your server. For a lab server accessible over the network, this might be something like `http://192.168.1.50/api/API_task_config.php` or `https://lab.ncmlab.ca/api/API_task_config.php`.

---

### 2.7 Security note for production

In `API_task_config.php` and `API_battery.php`, change the CORS header from:

```php
header('Access-Control-Allow-Origin: *');
```

to your JATOS server's origin only:

```php
header('Access-Control-Allow-Origin: https://your-jatos-server.ca');
```

This prevents other websites from querying your configuration database.

## Part 3 — Quick Reference: Useful MySQL Commands

```sql
-- Connect to the database
USE ncmbattery_config;

-- List all task types
SELECT task_type_id, task_name FROM task_types ORDER BY task_name;

-- List all parameter sets for Word Recall
SELECT parameter_name, language
FROM task_parameters tp
JOIN task_types tt ON tt.task_type_id = tp.task_type_id
WHERE tt.task_name = 'Word Recall';

-- List all instruction sets for Word Recall
SELECT instruction_name, language
FROM task_instructions ti
JOIN task_types tt ON tt.task_type_id = ti.task_type_id
WHERE tt.task_name = 'Word Recall';

-- View a full battery with all tasks
SELECT * FROM v_battery_tasks WHERE battery_index = 16;

-- Add a new parameter set for Word Recall
INSERT INTO task_parameters (task_type_id, parameter_name, language, parameters_json)
SELECT task_type_id, 'MyNewParameterSet', 'EN', '{"RecallType":"Manual", ...}'
FROM task_types WHERE task_name = 'Word Recall';

-- Update an existing parameter value inside the JSON
UPDATE task_parameters
SET parameters_json = JSON_SET(parameters_json, '$.RecallDuration', 90)
WHERE parameter_name = 'RAVLT_Spoken_Immediate';

-- Delete a parameter set
DELETE FROM task_parameters WHERE parameter_name = 'MyNewParameterSet';
```
